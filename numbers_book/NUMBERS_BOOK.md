## Ask Me Anything
- How much did we buy of material X? Use `material_360.csv` columns `Material_ID, ordered_qty, accepted_qty, accepted_spend_egp`.
- Which products lose money after discounts? Use `product_360.csv` columns `negative_profit_rows, negative_profit_sum_egp`.
- Which family has most overstock? Use `family_360.csv` columns `overstock_units_180, scenario_overstock_value_egp`.
- Which suppliers are late? Use `supplier_360.csv` columns `late_rate, mean_late_days`.
- Which channels have the best margin? Use `channel_360.csv` columns `gross_margin_pct, median_margin`.
- Which products have the highest return rate? Use `product_360.csv` columns `return_unit_rate, return_value_rate`.
- Which machines have downtime? Use `machine_360.csv` columns `downtime_hours, planned_downtime_share`.
- Which lines reject most units? Use `line_360.csv` columns `reject_rate, rejected_qty`.
- Which QC stage loses most EGP? Use `quality_360.csv` columns `loss_egp`.
- How stable is marketing efficiency? Use `marketing_360.csv` columns `spend_egp, roas, ctr`.
- What is monthly net sales? Use `time_360.csv` columns `month, net_sales_egp`.
- What is YoY sales change? Use `time_360.csv` columns `net_sales_yoy_change`.
- Which customer segments buy most? Use `customer_segments.csv` columns `net_sales_egp, buyers`.
- What is top customer decile share? Use `customer_deciles.csv` columns `cumulative_net_sales_share`.
- Which governorate-channel sells most? Use `geography.csv` columns `net_sales_egp`.
- Which products have BOM cost? Use `product_360.csv` columns `bom_cost_per_unit_egp`.
- Which materials are outside BOM? Use `material_360.csv` columns `in_bom`.
- What tickets take longest? Use `service_ops_360.csv` columns `median_resolution_hours, p90_resolution_hours`.
- Which business units have open issues? Use `group_operations_360.csv` columns `open_issues`.
- How do web orders trend? Use `web_360.csv` columns `orders, avg_conversion_rate`.
- How much stock is at each location? Use `location_360.csv` columns `stock_on_hand_latest, unit_months`.
- Which discount bands lose money? Use `channel_360_by_year.csv` columns `use sales_discount tables from outputs/tables`.
- How much did PO spend exceed COGS? Use `totals_and_checks.csv` columns `accepted_po_spend_vs_estimated_cogs`.
- Which columns look suspicious? Use `column_profiles.csv` columns `suspicious_scale`.
- What data does each raw file contain? Use `totals_and_checks.csv` columns `file_total rows and sums`.
